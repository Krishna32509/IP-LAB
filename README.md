# Digital Image Processing Assignments

This repository contains solutions for Assignments 1–4.

## Requirements

```bash
pip install opencv-python numpy
```

## Input Image

Place the input image in the root directory with the exact filename:

```text
image.jpg
```

Each program can be run independently from its assignment folder.

## Structure

- Assignment-1: Grayscale to Binary
- Assignment-2: RGB to Grayscale
- Assignment-3: Image Padding and Image Complement
- Assignment-4: Image Enhancement Techniques
